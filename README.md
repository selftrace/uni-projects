# uni-projects

These projects are mostly just me exploring the dataset and seeing what's going on before doing anything more complicated with it

What I did
>Loaded and cleaned the dataset
>Checked for missing values and duplicates
>Looked at the distributions of different features
>Explored relationships between variables
>Made visualizations to better understand the data
>Pointed out interesting patterns and anything that stood out

>Libraries Used:
pandas
numpy
matplotlib
scikit-learn (where needed)

The point of these projects wasn't really to build a model. It was to understand the data first, figure out what needs cleaning, and see if there are any obvious trends or problems.

This is mostly practice with exploratory data analysis. I wanted to get comfortable inspecting datasets, asking questions about them, and making plots that actually tell me something instead of just throwing graphs everywhere.

Nothing too crazy, just getting a good understanding of the data before moving on to anything else.
